# Plume 0.1.1

Local voice dictation for your desktop, now delivered with native installers.

Hold **Ctrl + Space**, speak, and release to insert text into the app you're using. Choose a model, download it once, and keep dictating offline. Audio, models, preferences and transcription history stay on your computer.

## Downloads

| Platform | Installer | Installation |
| --- | --- | --- |
| Windows x64 | `Plume-v0.1.1-x86_64-pc-windows-msvc.exe` | Run the installer, then open Plume from the Start menu. |
| macOS Apple Silicon | `Plume-v0.1.1-aarch64-apple-darwin.pkg` | Run the installer, then open Plume from Applications. |
| Ubuntu 24.04+ x64 (X11) | `Plume-v0.1.1-x86_64-unknown-linux-gnu.deb` | Install with `sudo apt install ./Plume-v0.1.1-x86_64-unknown-linux-gnu.deb`. |

Each installer has a separate SHA-256 checksum file. Speech models are downloaded from **Settings → Model** after installation.

## Changes

- Native installers replace portable ZIP and tar downloads.
- The standalone transcription CLI has been removed entirely, reducing the download size.
- Windows includes Start menu integration and an uninstaller. Linux includes a desktop entry and application icon.
- Updates download and verify the native installer, wait for Plume to close, then run the platform installer. User data is kept outside the installation folder.

## Upgrading from 0.1.0

Install this version manually using the download for your platform. The old updater expects the previous archive format. Close the old app before installing and use the newly installed Plume afterward. Your existing models, settings and history are preserved.

## Platform notes

- Installers are not publisher-signed or notarized; Windows or macOS may ask you to confirm opening them.
- Linux requires Ubuntu 24.04 or newer, X11 and a system tray. Wayland is not yet supported.
- On macOS, grant microphone, Accessibility and Input Monitoring permissions when requested.

Report issues at [GitHub Issues](https://github.com/LeoMartinDev/Plume/issues), including your operating system and selected model.
