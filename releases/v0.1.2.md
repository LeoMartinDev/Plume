# Plume 0.1.2

## Changes

- Fix Windows tray clicks: left-clicking the Plume icon opens and focuses Settings again.
- Complete the Plume rename across native window identifiers, Rust crates, logging, environment variables, packaging, CI and documentation.
- Store preferences, transcription history and models in the `plume` application folder.
- Improve shortcut capture when keys or modifiers are released, and handle modifier-only shortcuts on macOS.

## Downloads

Native installers are provided for Windows x64, macOS Apple Silicon and Ubuntu 24.04+ x64 (X11), each with a SHA-256 checksum. Speech models are downloaded separately from Settings.

This is a greenfield release: the former `stt` data folder is not migrated. Configure Plume and download your models in the new `plume` folder.
