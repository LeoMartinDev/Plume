# Plume 0.1.3

## Dictation

- Add hands-free dictation: press Ctrl+Shift+Space to start and again to stop. Hold-to-talk remains Ctrl+Space by default; both shortcuts are configurable.
- Keep one take active through microphone startup, transcription and insertion. Shortcuts pressed while busy require a release and a fresh press once ready.
- Cancel microphone capture and local Whisper/Nemotron transcription with Esc. Cancellation waits for native processing to stop and removes the take's audio.
- Share Silero speech detection between local engines. Silent takes produce no insertion or saved audio; voiced takes retain pauses and the release tail.
- Show recording, processing, insertion and cancellation feedback. Hands-free silence reminders appear after 30 seconds; recordings warn at nine minutes and stop at ten minutes.

## Recovery and insertion

- Retain the eight latest voiced recordings locally, including failed transcriptions, independently of text-history limits.
- Recover interrupted takes and retranscribe saved audio with the currently selected model and language. Recovered results remain readable and copyable without automatic insertion.
- Support deleting audio alone, deleting entries with their audio and clearing history. Save final text before attempting insertion.
- Restore supported clipboard content after paste, including text, HTML with text and images, while preserving a new user copy. Never attempt a second typing insertion after a dispatched paste.
- Adjust only boundary spacing when reliable macOS Accessibility or Windows UI Automation context is available. Unknown contexts, including X11, receive the exact transcription; focus is never returned to an earlier field.

## Desktop and installation

- Refine Settings, virtualize history scrolling, add insertion recovery cards and improve Windows tray reopening.
- Provide a macOS disk image with drag-and-drop installation into Applications.
- Fix Linux overlay window-handle access and the installer fixture on Windows so the native CI matrix can validate the release.

## Upgrading

The Plume rename introduced the `plume` application data folder. The former `stt` folder is not migrated automatically: users upgrading from 0.1.1 should configure Plume and prepare a model in Settings → Model before using dictation shortcuts. Quit earlier running instances before launching the new version.

Existing preferences in the `plume` folder and text history remain readable. A conflicting hands-free default preserves existing shortcuts and disables hands-free with a warning. Models and speech detection are prepared before dictation; no model download occurs during a take.

## Downloads and compatibility

Native installers are provided for macOS Apple Silicon, Windows x64 and Ubuntu 24.04+ x64 (X11), each with a SHA-256 checksum. Wayland is not supported. Speech models are downloaded separately inside the app.

Native dispatch confirms that keyboard events were sent; receiving-app behavior and permissions still depend on the target application and desktop environment.
