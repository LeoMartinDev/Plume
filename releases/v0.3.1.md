# Plume 0.3.1

## Fixes

- On macOS, updates no longer silently turn off your dictation shortcuts. Plume is now signed with the same certificate in every release, so macOS keeps its Microphone and Accessibility permissions across updates. You need to allow them one last time after installing this version.
- On macOS, if Plume starts without the Microphone or Accessibility permission, it opens the Permissions step again instead of ignoring your shortcuts.

## Improvements

- Plume writes a log file you can share when something goes wrong: `~/Library/Logs/Plume/plume.log` on macOS, `%LOCALAPPDATA%\plume\logs\plume.log` on Windows and `~/.local/share/plume/logs/plume.log` on Linux.
